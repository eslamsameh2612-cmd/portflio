## 💻 How to View Locally
Simply double-click `index.html` or open it with any web browser (Google Chrome, Microsoft Edge, Brave, etc.). No build step or local server required.

## 🖨️ Export to PDF / Print Resume
1. Click the **"Print / PDF"** button in the top navigation bar, or press `Ctrl + P` (`Cmd + P` on Mac).
2. The print stylesheet automatically formats the entire portfolio into a high-contrast, clean, ATS-compliant paper/PDF document.
3. Select "Save as PDF" as the destination.
